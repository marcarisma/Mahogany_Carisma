# Distance Calculator

Calculates for the distance between two points.

## How to run in VS code

First, you must get the file for the code. Second once your in VS code, open a new folder and click the file. Lastly just click the play button

## The Input Needed

The user must enter the coordinates of two points. It is represented by x1, y1, x2, and y2.

## Sample

After the user has entered the coordinates, it will then calculate the distance between the two points. For example, the coordinates are 2, 3, 7, 8. The answer will be 7.071.
